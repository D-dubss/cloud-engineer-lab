Home SOC Lab

Centralized logging and alert triage practice environment to simulate SOC workflows.

Objective

  • Build repeatable SOC workflows: ingestion → triage → investigation → documentation.
  • Practice detections with realistic telemetry (Windows events, Sysmon, network logs).

Tools / Stack

  • Windows endpoints + Sysmon
  • SIEM (Splunk / Sentinel / Elastic — pick the one you actually use)
  • Optional: Wazuh/OSSEC, Suricata, Zeek

What I Built

  • Log ingestion pipeline with consistent field normalization.
  • Dashboards for auth anomalies and process execution patterns.
  • Runbooks for common alert types (PowerShell, credential access, persistence).

Outcomes

  • Improved investigation speed by documenting repeatable queries + decision points.
  • Created baseline queries and tuning notes to reduce false positives.
